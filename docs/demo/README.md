# Optional jury presentation

The [canonical two-minute final-v4 package](final-v4/README.md) supplies the player built for [/judges/#walkthrough](https://tour-rescue.pages.dev/judges/#walkthrough). It includes the separate SOS sample and proposed agency/service-fee business model. The [100-second final-v2 package](final-v2/README.md) remains intact as an archive and rollback source.

One current publication MP4 supplies the build; the earlier MP4 remains in the archive. The build verifies the current film and caption assets before copying them into ignored `dist/video/`; video is excluded from the PWA shell cache. The current clean picture uses default native English captions. This package does not itself upload a film, update Devpost or establish a physical-device test.
